# `@caveman-ai/adapter-vercel-ai-sdk`

Exact-pinned Caveman adapter for `ai@7.0.43` `ToolLoopAgent`.

```bash
npm install @caveman-ai/agent @caveman-ai/adapter-vercel-ai-sdk ai@7.0.43
```

```js
import { createAdapter } from "@caveman-ai/adapter-vercel-ai-sdk";
```

Adapter validates locked build identity, terminal response identity, complete
provider usage, and public-catalog pricing. Capabilities remain experimental
until package conformance reports certify them.
